The engine is a loop

Think → act → look, until it can answer. Here it is reviewing Mrs. Delgado's chart (synthetic patient).

THINKFirst the latest EF, then each drug class.
ACTSearch notes for "ejection fraction"
LOOKEcho 8/29/26 LVEF 30%, newer than the 2024 problem-list "EF 45%" → HFrEF
ACTPull the medication list
LOOKNo MRA. Spironolactone stopped 4/14/26. Why?
ACTSearch notes for "spironolactone" → open the nephrology note
LOOKdiscontinued due to hyperkalemia (K 5.9) → medical exception, not a gap

3

Plan: break the big question into small ones

"Is there a gap?" is hard to check. "What is the latest EF?" is easy to check.

Let the AI read; let the rules decide. ✦ The model abstracts each small fact with a quote. The measure logic stays as fixed rules, the same way a human abstractor works from the CMS spec.
4

Rulebook: the instructions are a document

A "skill" is a short file of plain English that the agent opens when the task needs it.

--- name: gdmt-beta-blocker description: Decide whether an HFrEF patient is on evidence-based beta-blocker therapy. --- Counts: carvedilol, bisoprolol, metoprolol succinate. Metoprolol tartrate does NOT count. Use: any active prescription in the 12 months before discharge, through 7 days after. Not a gap if the chart documents a reason: systolic BP < 90 · asthma · a clinician's stated reason · the patient declines. Always quote the sentence you relied on.
Written by clinicians
In our study this is the same text the human chart reviewers followed. Agent and annotator share one rulebook.
Opened only when needed
Like pulling the pocket card for the one question in front of you. Dozens of skills, little clutter.
Readable, versioned, auditable
Change one line and the behaviour changes. Your QI committee can review it like a protocol.
5

Hands: tools are how it touches the chart

The same moves a human chart reviewer makes in Epic, offered to the model as a menu.

THE AGENT CAN ONLY DO WHAT IS ON THIS MENU
search_notes
Find notes that mention a word
≈ Chart Search
read_note
Open one note and read it
≈ clicking into the note
get_medications
Pull the structured med list
≈ the Meds tab
get_labs
Latest potassium, eGFR, BP
≈ Results Review
Read-only. One patient. One time window. Nothing else is attached, so it can't wander into another chart, and it can't place an order.
FHIR
The standard way EHRs share data. Our agents read either a research extract or a live FHIR interface, with nearly the same accuracy.
MCP
A standard "plug" for tools, like USB-C for AI. Build a tool once and any agent can use it.
